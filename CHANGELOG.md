# Changelog

## 0.2.0 research preview (2026-09-17)

Portable current-toolchain packages; explicit HTTPS discovery; CPU pacing options; participant registration revocation; signed remote operator CLI and endpoint; origin/boot binding, short-lived commands and replay prevention; reclaimed dropout slots and bounded replacement attempts; duplicate-connect protection; safer authentication and state validation; bounded status history and cached metrics; no private UI tokens in headless logs; downloadable status website; non-root Docker and durable-volume deployment template.

Still deliberately limited to a 65-parameter CPU workload with full replay verification. No GPU/LLM training, distributed weight shards, millions of nodes, financial rewards or ownership rights. Publisher signing, macOS notarization, independent security audit and broad clean-machine coverage remain incomplete. Ephemeral hosting is explicitly labeled.

## 0.1.0 local pilot

Signed built-in tasks, consent, pause, local UI, CPU training, replay verification and aggregate checkpoints. Historical tests used one host and separate processes.
