# Community-first roadmap

Status: design and community formation. The historical local CPU pilot remains a separate experiment. No public training rollout is promised for a particular install count.

1. Publish a readable, white, bilingual explanation and reviewable [architecture](docs/foundation/ARCHITECTURE.md). Establish GitHub Discussions and explicit governance. No compute enrollment.
2. Reproduce a small, frozen single-GPU baseline and a controlled distributed optimizer baseline. Select existing open components by evidence and reviewed licenses, not by marketing claims.
3. Define licensed data manifests, bounded execution, consent and notification behavior. Test 3–10 real devices on separate networks with interruption, restoration and corrupt-result scenarios.
4. Publish matched-quality energy, time, bandwidth and memory costs for a useful 10–50-GPU invited experiment. Do not call sampling or reputation a complete proof of computation.
5. Add independently operated discovery, mirrors, scheduling and checkpoint acceptance. Specify committee failure/partition rules; test failover and data repair.
6. Only then increase admitted public capacity, with reviewed distribution, signing, abuse controls and independent security evaluation.

These are proposed experiment scopes, not measured capacities. Native tray notifications, standing scoped consent, useful GPU workloads, a production Store release and full decentralization remain open work. The separate Community Preview deliberately cannot turn on training.
