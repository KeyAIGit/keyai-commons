What the pilot proves

A signed task can reach consenting clients. Clients train separate sample streams. Verified updates create a shared checkpoint. Disconnected nodes do not hold a round open indefinitely.

Training uses a 2 → 16 → 1 neural network with 65 parameters. This deliberately small workload makes the mechanism inspectable before any GPU-scale work.

What it does not promise

No million-node benchmark. No frontier model. No distributed weight shards yet. No token sale, paid credits or legal ownership stake. No claim of independent security certification.

The next gates are external machine testing, security review, scalable result validation, real GPU training and stable public hosting.

Open development pilot

Source code and explicitly labeled local-only demos are on GitHub. No public training coordinator is live. Read the release limitations before running unsigned software.
