A big ambition. An honest starting point.

What exists

Public source code, a local synthetic CPU experiment, and a community preview that cannot run training.

What still needs proof

Useful GPU training, economical communication, independent operators, robust verification and safe distribution. Millions of installs alone prove none of these.

Can a computer without a GPU help?

Yes. Small models can train on CPUs. Large-model training will focus on suitable GPUs; CPUs can support reviewed data preparation, evaluation and optional storage. Roles are planned, not available now.

Is the project fully decentralized today?

No. That is a design goal. We must remove dependence on one scheduler, one data host and one approval key, while keeping each participant in control.

Who accepts community code?

Anyone can propose a change. The maintainer reviews it after tests. Code review, campaign approval and permission on your computer are separate decisions.

Should I install the old training pilot?

Not to join the community. Older releases are developer experiments, not the public participation app. Broad installation waits for packaging, trust checks and invited tests.
