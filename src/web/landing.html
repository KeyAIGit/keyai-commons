A disconnected client does not block a round indefinitely. Available results are aggregated; abandoned task slots can be reassigned. A server restart never resumes a training round.

What is running?

A fixed 2 → 16 → 1 neural network learns a synthetic classification task. The model and generated data are small enough to inspect.

The verifier repeats all work. This catches incorrect submitted updates but does not save compute or prove million-node efficiency. CPU pacing is an application target, not a hardware power limit.

Learning history appears on the coordinator after completed rounds.

Your control is not optional.

No personal documents or chats are used. No remote shell, silent update or automatic startup. Permission expires and is never restored after an app restart.

Closing the browser tab is not exiting the app. Use Pause now or Exit application. The server sees your connection IP, OS/architecture and a random node identifier. Participants can revoke their registration.
