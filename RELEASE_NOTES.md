## An invited network research preview, not a production AI service

Download the package for your OS/architecture, fully extract it, and read START-HERE.txt. No compiler or Python runtime is needed. START-CLIENT starts a participant; LOCAL-DEMO starts an independent local demonstration. Network participation requires an organizer's HTTPS origin or code, explicit time-limited consent, and a separate operator start command.

New: HTTPS discovery; CPU pacing choices; registration revocation; signed remote operator commands; expiry, origin/boot binding and replay rejection; dropout-slot reassignment; indexed authentication; bounded status responses; live public status and a downloadable website; Docker/persistent-volume deployment templates.

**Scope:** 65-parameter CPU neural network, synthetic data, full reference replay. No GPU/LLM training, no proof of compute savings, no million-node benchmark, no payments, equity or guaranteed inference access. Pilot limits remain 256 registrations and 32 participants per round.

**Build provenance:** BUILD-MANIFEST.json records the source commit, compiler, target architectures and archive hashes. CI runs on Windows/Linux/macOS and adds Linux race, separate-process and real-browser tests. Passing these is not an independent security audit or a complete clean-machine hardware matrix.

**Unsigned binaries.** Windows publisher signing and macOS notarization are not included. Do not disable OS security controls. A checksum is not a publisher certificate.

**Hosting:** a website is not a coordinator. Ephemeral test hosts can sleep and lose identity, registration and model state after restart. Durable operation requires a persistent volume, HTTPS edge and private backups. Server restart never resumes training. Participants must reconnect explicitly after an ephemeral reset.
