# KeyAI Commons

Добровольная сеть для совместных исследований ИИ. Компьютер принадлежит участнику, разрешение и кнопка остановки остаются у него.

[Сайт](https://keyaigit.github.io/keyai-commons/) · [Скачать](https://github.com/KeyAIGit/keyai-commons/releases/tag/v0.2.0-pilot.1) · [Задачи](https://github.com/KeyAIGit/keyai-commons/issues) · [Обсуждения](https://github.com/KeyAIGit/keyai-commons/discussions)

## Запуск участника

1. Скачайте архив для своей ОС и архитектуры, полностью распакуйте его. Для Windows обычно нужен Windows-x64; для Mac с Apple Silicon нужен macOS-arm64.
2. Прочитайте START-HERE.txt. Запустите START-CLIENT.cmd на Windows либо ./start-client.sh на Linux/macOS. Go и Python не нужны.
3. Введите HTTPS-адрес координатора от организатора через Connect by HTTPS address. Альтернатива: код подключения с закреплённым публичным ключом. Доверяйте только знакомому организатору.
4. Выберите темп CPU 10%, 25% или 50% одного логического ядра, длительность сессии, отметьте согласие и нажмите Enable participation. Это программный темп, не аппаратный лимит мощности.
5. Клиент ждёт команды организатора. Pause now отзывает разрешение и останавливает вычисление. Exit application завершает программу.

Закрытие вкладки браузера само по себе не завершает клиент. Согласие никогда не восстанавливается автоматически после перезапуска. Нажатие Leave network and delete my registration отзывает регистрацию на сервере и удаляет локальный токен и локальную модель; координатор должен быть доступен. История общей модели этим не стирается.

Для опыта без интернета запустите LOCAL-DEMO.cmd либо ./local-demo.sh. Откроются клиент и отдельная панель организатора. Сначала согласие в клиенте, затем Start round в панели.

## Что это сейчас

Исследовательский предпросмотр 0.2.0. Действительно обучается небольшая CPU-нейросеть из 65 параметров на синтетических данных. Это не языковая модель, не GPU-система и не доказательство возможности обучить ASI. Нет выплат, токенов, долей собственности и гарантированного будущего доступа к ИИ.

Подписанные команды, сроки, восстановление свободных мест после отключений, проверка результатов и сохранение общей модели реализованы. Пределы пилота: 256 регистраций, 32 участника за раунд. Сервер повторяет все вычисления для проверки, поэтому выигрыша стоимости такая проверка пока не даёт.

## Ограничения распространения

Бинарники ещё не подписаны сертификатом издателя; macOS-нотарификация и независимый аудит не выполнены. Не отключайте защиту ОС ради запуска. Готовые архивы предназначены для согласованного тестирования.

Сайт GitHub Pages не является сервером обучения. Организатор отдельно запускает HTTPS-координатор. Бесплатный экспериментальный хост с временным диском может при перезапуске потерять регистрации, ключ задач и модель. Тогда требуется явное переподключение. Для длительной работы нужен постоянный диск и резервное копирование.

## Управление организатора

Инструкции и команды находятся в [deploy/README.md](deploy/README.md). Удалённые команды подписываются отдельным ключом организатора, привязаны к адресу и текущему запуску сервера, имеют короткий срок действия. Разрешены только начало/остановка/агрегация раунда и открытие/закрытие набора участников. Терминал и произвольные программы удалённо не запускаются.

Ключ организатора хранится только у организатора. Не публикуйте файлы с окончанием -private.json. Перезапуск сервера не возобновляет обучение автоматически.

Для сборки из исходников: Go 1.27.1+, затем `cd src`, `go test ./...`, `go build -o ../KeyAI-Commons.exe .`. Участникам, скачавшим готовую версию, компилятор не требуется.
